- ranking=2: emphasizes winner-versus-loser ordering.
  - listwise=2: strong enough to optimize the whole race without dominating the loss.
  - cardinality=0.3: encourages approximately three selections without sacrificing ranking.
  - residual-scale=1: gives RaceFormer freedom to overturn the market.
  - residual-weight=0: does not penalize disagreement with the market.
  - learning-rate=0.00005: appropriate for the sensitive market-residual formulation.
  - patience=10: allows early noise but stops sustained validation deterioration.

I added:

•  predict_moe_winner_ranker_feature_map.py 
• stricter feature-map enforcement in  src/model/race_moe_feature_map.py 
• example config at  configs/race_moe_feature_map.example.json 

Key change:

• No fallback is allowed anymore.
• Every feature must be explicitly assigned to at least one expert.
• Every expert must have at least one feature.
• If a feature is missing from the JSON, training fails fast.

Example JSON:

{
  "experts": {
    "0": ["distance_m", "distance_starts", "distance_wins"],
    "1": ["career_starts", "career_wins", "career_seconds"],
    "2": ["trackFamiliarity", "track_starts", "track_wins"],
    "3": ["recent_2_starting_price", "open_price", "fluc1"]
  }
}
